# 🐍 Python Projects

Small Python programs I'm building as I learn the language in my Programming I course at St. Francis College. Each one focuses on a few core concepts, and I'll keep adding new ones as my skills grow.

## Projects

| Program | What it does | Concepts |
|---|---|---|
| [`grade_calculator.py`](grade_calculator.py) | Takes a student's scores and calculates the average, highest, lowest, and letter grade | Functions, loops, lists, input validation |
| [`number_guessing_game.py`](number_guessing_game.py) | A game where you guess the computer's secret number with "too high / too low" hints | `random` module, while loops, counters |
| [`todo_list.py`](todo_list.py) | A command-line to-do list that saves your tasks to a file | File reading/writing, menus, lists |

## How to run

You need [Python 3](https://www.python.org/downloads/) installed. Then, from this folder:

```bash
python grade_calculator.py
python number_guessing_game.py
python todo_list.py
```

(On Mac/Linux you may need to type `python3` instead of `python`.)

## What I'm learning

- Breaking a problem into small functions
- Checking user input so the program doesn't crash
- Saving data to files so it lasts between runs
